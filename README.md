# Sparkling Spaces Tidy Mamas - Professional Cleaning Website

A modern, responsive website for **Sparkling Spaces Tidy Mamas** home cleaning services.

## Features
- Fully responsive design (mobile, tablet, desktop)
- Professional green theme matching the brand
- Hero section with call-to-action
- Services showcase
- Why choose us section
- How it works process steps
- Special offers / deals section
- Customer reviews
- Contact form (sends email)
- Sticky header + mobile menu
- Smooth scrolling & animations

## How to Use
1. Open `index.html` in any modern browser
2. Or upload the entire folder to any web hosting (Netlify, Vercel, cPanel, etc.)
